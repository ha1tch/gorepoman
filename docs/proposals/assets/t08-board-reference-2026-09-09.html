Tier placement follows the recorded Blocks/after field on each register item, computed transitively by hand (tier = 1 + the deepest tier among an item's own blockers; unblocked items sit at Now). T-08's own blocker (T-06) is not listed above because T-06 is already closed — a dependency on shipped work doesn't hold an item back. No manual overrides were applied: every placement here follows directly from the register's own Blocks column, unlike the automated tiering T-08 itself will eventually provide. Every card in Now now carries an explicit tag — a grey "unblocked, no dependents" checkmark where a card doesn't gate anything else, so an unblocked item with nothing downstream doesn't read the same as one not yet classified.

T-20 and T-21 are marked code complete, pending release (register Status: ◑, gorepoman's own kanban symbol for this state): implemented, gofmt/vet/build clean, and the full selftest gate green (ed: 19/19, top-level: 150/150), but not yet in a tagged release. Tier placement is unaffected — they still sit in Now because nothing blocks them — but neither is actually "ready to start" from scratch the way the rest of the Now column is; the 8/10 "ready to start" figure above excludes them.
